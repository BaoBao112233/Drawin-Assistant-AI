🎯 FEATURES CHÍNH

✅ Multi-Agent Architecture
   - Supervisor Agent (routing)
   - SQL Writer Agent (generate SQL)
   - Doc Reader Agent (documentation)
   - Validator Agent (trust scoring)

✅ Knowledge-First Approach
   - Metadata retrieval BEFORE SQL generation
   - Business term resolution (USNC → US and Canada)
   - NO AI hallucination

✅ AI Gateway
   - OpenAI (gpt-4o-mini)
   - Google Gemini (fallback)
   - Local model (stub)
   - Automatic fallback

✅ Security
   - Read-only SQL enforcement
   - Query timeout (5s)
   - Rate limiting (30 req/min)
   - SQL injection prevention

✅ Golden Query Validation
   - Trust score calculation
   - Result comparison
   - Human-in-the-loop

✅ Database
   - 10 transactional tables (users, drivers, trips...)
   - 2 flattened analytics tables
   - 10,000+ records
   - Full indexing

✅ UI
   - Chat interface
   - Database explorer
   - Query history
   - Trust scores

🐛 TROUBLESHOOTING

Problem: Database connection error
→ docker compose up -d postgres
→ Wait 10 seconds

Problem: OpenAI API error
→ Check .env has correct OPENAI_API_KEY

Problem: Import errors
→ source venv/bin/activate
→ pip install -r requirements.txt

Problem: No data in database
→ python seed_data.py
